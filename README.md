# Retention & LTV Simulator

Model a subscriber cohort: retention, lifetime value, LTV to CAC and payback.
**[Try it live](https://adrienbalcioglu.github.io/retention-ltv-simulator/)**


## Features

- Separate first-month drop and steady monthly retention
- Lifetime value on gross margin, LTV to CAC ratio and payback month
- Chart of cumulative margin against acquisition cost
- Month-by-month table

## Usage

Open `index.html` in a browser. There is nothing to install and nothing to build. Nothing is stored or sent anywhere.

## Stack

HTML, CSS, JavaScript and inline SVG in a single file. No dependency.
